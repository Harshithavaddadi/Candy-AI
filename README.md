# 🍬 Candy AI

Candy AI is a modern AI-powered chatbot web application built with Next.js and modern web technologies. It provides an interactive and responsive user experience with intelligent conversational capabilities.

---

## 🚀 Features

- Modern and responsive UI
- AI chatbot interaction
- Fast and smooth performance
- User-friendly design
- Built using modern web technologies

---

## 🛠️ Tech Stack

- Next.js
- React.js
- JavaScript
- Node.js
- Tailwind CSS

---

## 📂 Project Setup

Clone the repository:

```bash
git clone https://github.com/Harshithavaddadi/Candy-AI.git
```

Move into the project folder:

```bash
cd Candy-AI
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open in browser:

```text
http://localhost:3000
```
